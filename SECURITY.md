# Security policy

## Supported versions

Security fixes are applied to the latest published minor release.

| Version | Supported |
| --- | --- |
| 1.1.x | Yes |
| 1.0.x | No |

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/Sylverity/petls-pytorch/security/advisories/new)
to contact the maintainers privately.

Include the affected version, impact, reproduction steps, and any proposed mitigation. You can
expect an acknowledgement within seven days. We will coordinate validation, remediation, and
disclosure with the reporter and credit the report unless anonymity is requested.

For ordinary bugs that do not have a security impact, use the public bug-report template.
