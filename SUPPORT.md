# Support

- Ask usage and design questions in [GitHub
  Discussions](https://github.com/Sylverity/petls-pytorch/discussions).
- Report reproducible bugs with the [bug-report
  form](https://github.com/Sylverity/petls-pytorch/issues/new/choose).
- Propose focused enhancements with the feature-request form.
- Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Please include the package version, Python and PyTorch versions, operating system, device, CUDA
version when applicable, dtype, a minimal example, and the full error output. Community support
is provided on a best-effort basis.
